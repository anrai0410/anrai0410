## Hi, I'm Aditya 👋

**QA Automation Engineer / Software Developer** focused on building reliable test automation, practical web applications, and developer tooling.

I work across **Java, TypeScript, JavaScript, Playwright, API automation, and CI/CD-oriented workflows**. I enjoy turning repetitive processes into maintainable, well-structured solutions and continuously improving the quality of software delivery.

## What I work on

- 🧪 **UI and API automation** with Playwright, TestNG, Maven, and REST Assured
- 🏗️ **Production-minded web applications** with Next.js, TypeScript, Prisma, and Supabase
- 🔧 **Test architecture** using Page Object Model, service abstractions, reusable utilities, and reporting
- 📚 **Interview preparation and automation testing fundamentals**
- ☁️ **Automation-aware development** with attention to security, reliability, and platform constraints

## Featured projects

### 🚆 [RailVac — Chart Vacancy Viewer](https://github.com/anrai0410/railvac)
A Next.js and TypeScript application for viewing Indian Railways chart vacancy data. It uses a feature-based architecture and a pluggable service layer so demo data can be replaced with a live provider.

**Stack:** Next.js · React · TypeScript · Prisma · Supabase · Zod · Playwright

### 🎭 [Playwright Java Framework](https://github.com/anrai0410/playwright_java_framework)
A Maven-based Java automation framework using Playwright and TestNG. It demonstrates Page Object Model design, centralized selectors and configuration, browser lifecycle management, and ExtentReports.

**Stack:** Java 11 · Maven · Playwright Java · TestNG · ExtentReports

### 🤖 [Naukari-Agentic-Updater](https://github.com/anrai0410/Naukari-Agentic-Updater)
A browser-automation experiment exploring Playwright workflows, session handling, and the practical security and reliability constraints of automating protected third-party platforms.

### 📘 [Interview](https://github.com/anrai0410/Interview)
A concise collection of automation testing interview questions covering fundamentals, framework design, TestNG, Page Object Model, dynamic elements, and Playwright.
